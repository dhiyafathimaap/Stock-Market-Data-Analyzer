# 📈 Stock Market Data Analyzer

A professional Python-based engine designed to automate the extraction, processing, and visualization of stock market data. This project demonstrates a modular approach to financial data engineering.

## 🌟 Key Features
- **Live Data Fetching:** Seamless integration with Yahoo Finance API via `yfinance`.
- **Quantitative Analysis:** Calculates 50-day and 200-day Simple Moving Averages (SMA) to identify market trends.
- **Risk Metrics:** Computes annualized volatility and daily return distributions.
- **Automated Visualization:** Generates professional-grade charts for price trends and statistical distributions.
- **Modular Architecture:** Clean separation of concerns between data retrieval, logic, and output.

## 🛠️ Technical Stack
- **Language:** Python 3.x
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **API Connectivity:** yfinance

## 📂 Project Structure
- `main.py`: The central controller that runs the analysis pipeline.
- `src/`: Core engine containing modular scripts for fetching, processing, and plotting.
- `data/`: Local storage for raw CSV datasets (git-ignored).
- `outputs/`: Destination for generated analysis charts (git-ignored).
